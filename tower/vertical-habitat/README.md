# VERTICAL HABITAT / 01

V1.0 — standalone experimental porous tower field generator.

Live: https://haowang310.github.io/Special-Parcel-Test/tower/vertical-habitat/

Single HTML; no build step or external libraries. Four typologies, nine surface functions, volumetric field union, XYZ section, program sampling, continuous geometric reveal animation and indexed OBJ export (metres; Z up). Use `?renderer=cpu` for software rendering. Candidate program zones are not verified dwellings; the route is a centreline study, not a built stair or compliant egress system. The mixed fields are not exact minimal surfaces; geometry checks are not engineering validation.

Future revisions to this particular version should update `tower/vertical-habitat/index.html` on main. The existing tower/index.html, habitat/ and root app are preserved.
